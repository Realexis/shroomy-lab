# Shroomy LAB

R&D copy of ShroomyMap (Cyprus forest mushroom growing **conditions**). Not the live site.

- `site/` — the lab copy of the website (web app in `site/web/`, pipeline in `site/pipeline/`)
- `data/finds/` — public mushroom records (iNaturalist, GBIF)
- `experiments/` — one subfolder per experiment
- `reports/` — results
- `NOTES.md` — running log

Start locally: `bash start.sh` → http://localhost:5190/  ·  Publish by hand: `bash publish.sh`

Conditions only. Never eat a wild mushroom based on this map, an app or an AI. Emergency 112 · Poison Centre 1401.
